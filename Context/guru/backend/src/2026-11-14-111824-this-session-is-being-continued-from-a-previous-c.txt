  +0.25% on every flat bar of a down trend and sells on a break of the
  down-flip Low. It is coded that way and said in the notes, but it is probably
  not what the authors meant, so it is worth a look before you publish.
    - **Scale-in:** ATR(14) has no value on the first 14 bars, so the first bars
  of the data add a unit on every bar.
    - **ATHC +5%:** a buy with no trigger set is possible only in a rare case (a
  new high while the swing is down).
  - **Same-bar buy and sell (High/Low AFL):** the backtester enters and ignores
  that bar's sale, because the AFL does not set AllowSameBarExit
  (`ytd7::fills`). I set its `entry_kind` to "stop".
  - **Consecutive-loss count:** the AFL's `Cross(Ref(TrendUp1,-1), C)` is
  computed exactly as "the bar the swing turns down, from bar 3"; the reasoning
  is in the code comment. The brokerage 0.65 comes from the AFL's BROKERAGE
  Param and is used only for this count.
  - **MultiTimeFrame stale header:** the AFL's header says "N Red Candles" and
  "5-2 5-4", but its code uses ST 5,1 and 5,2; the code is followed. On the
  data's last bar the weekly filter has no value, so the filter exit fires
  there.
