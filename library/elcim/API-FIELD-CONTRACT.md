`report_mode` changes only the closed-trade display statistic. It must not imply switching the book's mandatory risk sizing, turning protection off, or changing the executed ledger. The page needs separate labels for closed-trade return display and the actual risk-sized account curve. Single-stock account execution is not basket execution; no equal-slot portfolio is admitted by this candidate.

Costs retain the platform's explicitly declared entry-notional bps convention. Slippage is a return deduction, not a rewritten fill price. Both planned sides fit the initial risk budget, but an unexecuted exit is never charged to an open mark. Gross removes only costs already paid and keeps the same quantities. Rollover remains unsupported for these cash-stock inputs.

The exact `elcim_impulse` HTTP contract validates every supplied parameter against its reviewed schema. Infinite endpoints, tiny steps producing excessive counts, unknown fields and near-default alternatives are rejected with a normal error response. Open holdings have actual entry costs and zero invented exit cost.

Execution order is fixed and causal:

1. Before each actual open, a new month first resets the reference to the previous actual closing equity, resets monthly realized-loss allowance/halt state, and recalibrates an existing stop to the 2% monthly risk ceiling without loosening it. A liquidation already queued at the previous close is retained across this reset. If expected exit costs alone cannot fit the new 2% allowance, a risk liquidation is also required; costs are never erased.
2. A previously queued risk liquidation takes priority over a prior-close daily Impulse exit; either fills at the actual open. Both market exits take priority over the known protective order, so a gap touching both does not create two exits. The fill is the same actual open; the stated reason follows this priority.
3. If still held, update/ratchet the known SafeZone order using only earlier observations. If flat both now and at the prior close, consider a fresh source signal, source weekly filter, known initial protection and cost-aware risk/cash budget. A position exited at this open cannot invent a same-open reversal or re-entry. The first selected bar begins flat without an inherited pending order; the earliest signal comes from its close.
4. A market-at-open entry has its previously known protective stop immediately active. For an already-held or newly entered position, a gap through that stop fills at the actual open, otherwise an observed touch fills at the known stop. No intraday stop-entry path is guessed.
5. Mark remaining holdings at the actual close, charge only transactions that occurred, record conservation/risk, and queue a 6% account liquidation/halt if required. There is no invented future exit for a terminal pending order or open holding.

SafeZone precision/undefined convention is explicit. The 10 penetration observations require 11 actual high/low source bars. Today's raw stop uses the previous day's **unrounded** penetration mean; today's protected level requires **all three** most recent raw levels to exist. A zero penetration count leaves the mean/raw level undefined, and MAX/MIN never skips undefined inputs to manufacture a fresh level. No new entry is accepted without a valid protective level. An existing position retains its last known stop if a newly calculated level is undefined, and otherwise never loosens it (printed174). The source worksheet's displayed cents are an arithmetic fixture, not rounding applied before execution. Printed179 discretionary turning-point/lookback resets are not mechanically reproduced by the fixed10/2 composition.
